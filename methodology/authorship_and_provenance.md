## Integrity rule

The project must not:
- attribute invented quotations to Fitzgerald;
- imply use of a published translation when the project created the translation;
- conceal material changes between language versions;
- describe GitHub as proof of correctness by itself;
- claim professional AI experience or AI-model deployment that this project does not establish.

GitHub records the QA process. Verification quality still depends on the evidence and checks documented there.
